## 当前能力与诚实降级

- 对话、记忆、计划、情绪、设置、备份/恢复和提醒都写入本地 SQLite。
- 本地音乐支持多文件队列、上一首/下一首、进度、自动续播；不随仓库分发音乐文件。
- 未配置 `XINYU_SPEECH_REALTIME_URL` 时，语音界面会明确显示不可用原因，不会申请麦克风或伪造语音能力。
- 人物默认显示已批准的静态场景。只有运行数据目录中四个必需状态视频都存在时，才启用视频状态库；首帧可播放前保持静态图，避免黑屏。
- 诊断报告不包含消息正文、记忆正文、数据库路径、麦克风设备 ID 或密钥。

## 下一阶段建议顺序

1. 在目标机器选定并安装可承受的 STT / LLM / TTS，填写环境变量后做真实延迟、回声和长时稳定性基准。
2. 获得明确授权的人物素材，按 `docs/AVATAR_ASSETS.md` 制作 `idle`、`listening`、`thinking`、`speaking` 等状态视频；之后再接入 LivePortrait / MuseTalk 局部驱动。
3. 给记忆加入向量召回与对话摘要压缩；保留现有 FTS5 作为回退。
4. 安装 Rust stable MSVC 后运行 `npm run tauri:dev` 与 `npm run tauri:build`，验收托盘、通知、开机启动和安装包。
5. 最后再接日历、天气等外部授权服务，并完成素材、模型、字体、音乐和代码签名的发布审查。
