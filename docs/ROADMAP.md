# 产品与开发路线图

路线图按“先形成可信的陪伴体验，再增加模型复杂度”排序。日期在硬件基准和开发人力确定后再排。

## M0：可演示 UI（已完成）

- [x] 16:9 主场景与响应式布局
- [x] 水晶心 Logo 和心跳动效
- [x] 此刻、对话、回忆、计划、更多页面切换
- [x] 音乐、输入、心情、点滴和清单的演示交互
- [x] 生产构建和基础 Worker 测试

退出条件：另一台电脑能从仓库克隆、安装、构建并运行 Demo。

## M1：桌面壳与本地数据

- [x] 接入 Tauri 2 工程、品牌图标和自动构建的 Core sidecar
- [ ] Windows 安装包、托盘、开机启动开关
- [x] SQLite 数据库与迁移
- [x] 对话、计划和设置的真实 CRUD
- [x] JSON 数据导入（版本校验、二次确认、导入前安全快照）
- [x] 数据导出与二次确认删除
- [x] 数据库快照、恢复和自动保留最近 10 份

退出条件：断网后仍能使用 UI、保存计划和浏览历史。

## M2：可打断的实时语音

- [x] 麦克风权限与设备选择
- [ ] VAD、流式 STT、LLM、流式 TTS Provider
- [x] WebSocket 事件协议与 Core 双向代理
- [x] 上游播放队列与用户插话清空逻辑接入
- [x] 最终转写幂等持久化与语音明确记忆提取
- [ ] 延迟、错误和设备状态可观测

目标指标（首轮基准，不是承诺值）：

- 用户停止说话到首个回复音频：本地高性能设备争取 1.5 秒内
- 用户插话到停止播报：争取 250 毫秒内
- 连续 30 分钟对话无音频队列失控

## M3：长期记忆

- [x] 从用户明确表达中提取记忆候选
- [x] 用户确认、纠错、置顶和删除
- [x] FTS5 与中文短查询回退
- [ ] 语义向量检索
- [x] 回答中显示“为什么想起这件事”与来源消息
- [x] 同槽记忆冲突替代与未确认推断过期策略
- [ ] 长对话记忆摘要压缩

退出条件：角色能稳定记住关键偏好与共同事件，同时用户能完全控制这些记忆。

## M4：动态人物

- [x] 建立 `idle / listening / thinking / speaking / smiling / goodnight` 状态契约、事件与静态诚实回退
- [x] 建立本地视频资产安全路由、前端淡入播放和 Tauri 媒体 CSP
- [ ] 建立固定 `character_id`、角色参考集和资产许可证清单
- [ ] 使用 LivePortrait 离线生成写实待机、倾听、思考、微笑和晚安状态视频
- [ ] 根据语音状态和情绪无缝切换写实视频片段
- [ ] 接入 MuseTalk 或同类方案，只生成脸部兴趣区域的音频驱动口型
- [ ] 建立带音频时间戳的解码、推理、合成和播放队列
- [ ] 验证 720p/25fps、1080p/25fps、首帧延迟和长时间身份漂移
- [ ] 显存不足时回退到高质量预制说话视频，不采用 2.5D 默认模式

退出条件：人物在待机、倾听、思考、说话和被打断时都有自然且可恢复的状态。

## M5：主动陪伴与工具

- [ ] 日程、天气和媒体库工具
- [x] 本地计划提醒、安静时段和实时事件
- [x] 有频率上限、同主题冷却和独立开关的温柔问候
- [x] 安静时段、勿扰开关与错过提醒收件箱
- [ ] 关系状态随真实互动缓慢变化
- [ ] 记忆与计划联动

退出条件：主动行为有明确来源、可以关闭，不使用内疚或依赖诱导文案。

## M6：质量与发布

- [x] 数据库备份、完整性校验、导入前安全快照和恢复
- [x] CPU / GPU / 内存诊断与推荐档位
- [ ] 隐私说明、第三方许可和素材权利审查
- [ ] 自动更新与版本回滚
- [ ] 安装包签名和发布流程
