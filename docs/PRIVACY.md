# 隐私与数据说明（开发版）

心屿采用本地优先架构。本文记录当前代码实际的数据行为，不把尚未完成的能力
写成承诺。

## 默认保存在本机的数据

- 对话会话和消息正文；
- 用户确认或主动添加的记忆、来源消息 ID、置信度和替代关系；
- 用户可查看、删除和主动重建的对话摘要；
- 计划、提醒、已读状态和受限频率的主动问候记录；
- 人格版本、心情状态、晚安心语和功能开关；
- 本地数据库快照；
- 用户本次选择的麦克风设备 ID。

数据位于当前系统用户的应用数据目录。开发模式默认使用仓库
`temp/runtime/`。SQLite 当前**没有应用层静态加密**，安全性依赖 Windows
账户、磁盘加密和文件权限；不要在共用系统账户中保存高度敏感内容。

## 网络与模型数据流

- 未设置 `XINYU_LLM_BASE_URL` 时不会把文字对话发送给外部 LLM；开发回退
  Provider 只在本机运行。
- 对话摘要只交给已明确配置的真实 LLM，开发回退不会伪造摘要。
- 未设置 `XINYU_EMBEDDING_BASE_URL` 时只使用本地 FTS5/LIKE；配置后，记忆查询
  文本和待索引记忆正文会发送到用户指定的 embedding 地址。
- 未设置且未启动 `XINYU_SPEECH_REALTIME_URL` 时不会申请麦克风权限，也不会
  发送音频。
- 配置远程 Provider 后，对话或音频会流向用户明确配置的地址；设置页必须显示
  对应组件状态。API 密钥来自进程环境变量，不写入 SQLite、导出文件或诊断报告。
- 天气目前显示“未连接”，没有后台定位或天气请求。
- 本机音乐通过浏览器对象 URL 播放，不上传文件；替换歌单或退出时释放 URL。

## 麦克风、通知和开机启动

- 打开页面或设置页不会静默请求麦克风；只有点击“开始语音输入”或显式点击
  “检测麦克风”才调用系统权限接口。
- 停止语音或发生错误时关闭 WebSocket、AudioContext 并停止麦克风轨道。
- 系统通知和开机启动只在 Tauri 安装版中调用原生插件；网页演示不会修改系统。

## 主动陪伴边界

- 全局主动陪伴和“温柔问候”可分别关闭；
- 问候只在已有真实互动且长时间未交流时评估；
- 遵守安静时段、同类冷却和每日上限；计划提醒不占问候额度；
- 不使用虚构紧急事件、内疚、威胁离开或依赖诱导文案；
- 每个主动事件保留触发类型、原因、时间和已读状态。

## 用户控制

设置页提供完整 JSON 导出、数据库快照、恢复、导入和清除。恢复、导入和清除
需要再次确认；导入或清除前先创建安全快照。记忆页面可以查看“为什么记得”、
修正、收藏或忘记单条记忆。
摘要页面可以查看生成模型和覆盖消息数、删除摘要或主动重建；删除后摘要立即停止
进入聊天上下文。JSON 导出包含摘要正文，但不包含可重建的向量索引。

“导出脱敏诊断报告”只包含版本、数据库健康状态、记录数量、组件状态、硬件概况
和功能开关；不包含消息正文、记忆正文、文件路径、麦克风设备 ID、令牌或密钥。

## 人物、声音和素材权利

角色图片、状态视频、声音和模型权重在发布前必须完成来源、肖像、声音、模型
许可证和商用范围审核。声音克隆必须取得声音权利人明确同意。未完成审核的素材
只能用于本机原型。

## 当前开发限制

- 尚未提供应用层数据库加密和系统凭据库封装；
- 尚未完成签名安装包、自动更新和正式隐私政策法务审核；
- 真实语音模型、女声和动态人物素材仍需人工选择与权利验收；
- 诊断报告虽由自动测试确认不含业务正文，正式发布前仍需再次安全审计。
