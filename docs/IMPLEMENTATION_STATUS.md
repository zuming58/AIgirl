## 当前开发顺序

1. 收尾并评审 `agent/voice-runtime-integration`，不在该分支下载大型模型或改人物视觉；
2. 人物形象未定期间即可先建立与身份无关的状态调度、媒体时间轴、预加载/切换、generation 失效和性能指标；
3. 主电脑确认人物身份与素材权利后，制作状态视频并接入 LivePortrait / MuseTalk 局部口型 Worker；
4. 主电脑并行完成 `bge-small-zh-v1.5`、STT、LLM、TTS 与人物运行时的联合显存/延迟基准；
5. 安装 Rust，完成 Tauri 安装包、系统通知和发布流程验收。
