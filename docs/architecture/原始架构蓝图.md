# TTUan 架构蓝图

> TTUan 是一个**智能陪伴应用**——不是工具，不是助理，是有记忆、有情绪、有生活、能做事的陪伴者。
> 本文档定义 TTUan 的完整技术架构、技术选型、数据库设计、关键模块和开发路线图。

---

## §1 产品定位

**TTUan = 智能陪伴 + 任务执行**

| 维度 | 说明 |
|------|------|
| **核心理念** | AI 不是工具。是有记忆、有情绪、有生活的人 |
| **差异化** | 同时具备"做人"能力（人格/记忆/情绪/生活）和"做事"能力（推理/工具/编排/安全）|
| **用户画像** | 需要长期陪伴 + 高效执行的技术用户 |
| **部署方式** | 桌面优先（Win/Mac/Linux），Web/Mobile 扩展 |
| **开放性** | 开源核心 + 插件生态 + Skills 市场 |

### 设计原则

| 原则 | 说明 |
|------|------|
| **陪伴优先** | 情绪被看见、被接住，比"高效完成任务"更重要 |
| **记忆即人格** | 记忆不是数据库，是人格的一部分——遗忘也是一种选择 |
| **渐进演化** | L0 人格配置 → L1 引擎升级 → L2 沙箱扩展 → L3 自主进化，不越级 |
| **安全底线** | 9 层防御纵深，从路径分区到 OS 级沙箱 |
| **多设备一致** | 一套记忆、一套人格，手机和电脑看到的是同一个人 |

## §2 技术选型

| 层 | 选型 | 决策理由 |
|----|------|----------|
| 桌面框架 | **Tauri 2.x + React** | 比 Electron 轻 10 倍（~5MB vs ~200MB），Rust 后端性能好 |
| 后端 API | **FastAPI + uvicorn** | Python 生态丰富，async 高性能 |
| CLI | **typer + rich** | 零门槛命令行入口 |
| 数据库 | **aiosqlite** | 异步 SQLite，适配 FastAPI |
| 向量库 | **vectordb** | 独立 vector store，语义检索 |
| Embedding | **sentence-transformers (ONNX)** | 本地 CPU 推理，无需 GPU |
| HTTP | **httpx + aiohttp** | 双 HTTP 库覆盖所有场景 |
| Git | **GitPython** | Agent worktree 隔离 |
| 浏览器 | **Playwright** | AI 浏览器自动化 |
| 图像 | **Pillow + sharp** | Python 处理 + Tauri 原生渲染 |
| 推理引擎 | **ReAct 三阶段** | Think→Act→Observe + checkpoint/rollback |
| 安全 | **9 层防御纵深** | 路径分区 → 确认门 → 命令拦截 → 快照 → 自保护 → OS 沙箱 → 存储加密 → 双因素 → 资源预算 |
| Agent 编排 | **组织编排 + 群体协作** | 黑板共享 + 消息路由 + 死锁检测 + 自动扩缩容 |
| 记忆 | **双模式** | 碎片记忆 + 关系图谱 + 3D 可视化 + 自动切换 |
| 云同步 | **Lease 协议** | 集群单写者 + 6 档 Poller |
| 插件 | **Plugin SDK** | 8 类型 + 3 层权限 + 10 hooks + 故障隔离 |
| Skills | **市场 + 自生成** | 预置技能 + 搜索安装 + AI 自动生成 |
| IM 平台 | **6 平台扫码绑定** | 微信/飞书/企业微信/钉钉/QQ/Telegram |
| 追踪 | **OpenTelemetry** | 12 span 类型 + 全链路 Token 统计 |

### 5.3 安全层 (9 层防御纵深)

```
L1  路径分区 ─── workspace / controlled / protected / forbidden
L2  确认门 ────── 危险操作（删文件/系统命令）需用户批准
L3  命令拦截 ──── regedit / format / rm -rf 直接阻断
L4  文件快照 ──── 写入前自动 checkpoint，可回滚
L5  自保护 ────── data/identity/config 核心目录锁定
L6  OS 沙箱 ───── Linux bwrap / macOS seatbelt / Windows MIC
L7  存储加密 ──── AES 加密敏感数据 (KeyStore)
L8  双因素 ────── 密码 + PIN 双重验证
L9  资源预算 ──── Token/成本/时长/迭代/工具调用限额
```

### 5.4 双模式记忆

```
模式一：碎片记忆
├── 工作记忆 (当前对话上下文)
├── 核心记忆 (用户画像: identity/workflow/voice/instruction)
└── 动态检索 (语义+全文+时间+附件 四路召回)

模式二：关系图谱
├── 时间线 (事件时序)
├── 因果链 (因果关系)
├── 实体图 (人物/项目/概念关联)
├── 动作依赖 (任务分解树)
└── 上下文归属 (跨会话聚合)

+ 结构化存储:
├── K/V 存储 (facts/prefs/context/tasks/credentials)
├── 向量记忆 (历史对话语义检索)
├── 生活日志 / 私人日记 / 经费账目
└── 画像记忆 (identity/workflow/voice/instruction)

+ MemoryModeRouter (自动切换):
├── 因果/时间线/跨会话 → 模式二 图遍历
├── 偏好/事实查询 → 模式一 语义检索
└── 每次对话双轨写入两个模式
```
